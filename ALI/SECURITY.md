# سياسة أمان ALI Runtime

- الربط الافتراضي Loopback فقط (`127.0.0.1`).
- الوصول غير المحلي يتطلب `ALI_API_TOKEN`.
- حجم طلب HTTP محدود افتراضيًا إلى 1 MiB.
- يوجد Rate Limit على مستوى عنوان العميل.
- المسارات النسبية فقط، مع رفض traversal وdrive-qualified paths.
- عمليات الكتابة/الحذف/إنشاء المجلدات لا تعني موافقة ضمنية؛ التنفيذ يحتاج `approved=true`.
- idempotency تمنع إعادة تشغيل العملية نفسها بشكل غير مقصود.
- audit trail محفوظ في SQLite/WAL داخل مساحة التشغيل.
- لا تُطبع الرموز والحقول الحساسة في مخرجات JSON.
- لا تحتوي ملفات المصدر على أسرار أو مفاتيح فعلية.
