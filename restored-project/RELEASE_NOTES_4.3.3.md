# ALI Studio Pro 4.3.3

## إصلاح مركز التدريب التراكمي

- إضافة تقدم تدريب موثوق: `step/total_steps`, النسبة، العينات، tokens، السرعة، الوقت المنقضي، ETA وLoss.
- تصحيح مشكلة كانت تجعل نسبة التدريب تقف تقريبًا عند 80% أثناء الخطوات بسبب غياب `total_steps` في طبقة العرض.
- عرض نتيجة الاستيراد بوضوح: المقبول، العينات، RAG فقط، المكرر والمرفوض.
- إعادة تحميل النموذج الجديد تلقائيًا بعد Promotion الناجح حتى يكون هو النموذج المستخدم في المحادثة.
- توضيح الفرق بين `Completed + Active` و`Completed + Candidate`.
- توحيد رقم الإصدار في ملفات المشروع والاختبارات إلى 4.3.3.
